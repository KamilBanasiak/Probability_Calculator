# Probability\_Calculator

This repository contains the last project from the **Scientific Computing with Python** course on freeCodeCamp.

## Purpose

The goal of this repository is to practice Python by completing the project from the course.

## Features

* Creates a hat containing balls of different colors
* Supports multiple balls of each color
* Draws a specified number of balls randomly
* Removes drawn balls from the hat
* Simulates multiple drawing experiments
* Checks whether the expected balls were drawn
* Calculates the probability of drawing the expected balls
